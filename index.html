How it works

  1. Record the meeting with iPhone Voice Memos
  2. Share the recording → Save to Files
  3. In this app: New transcription → pick that file
  4. Name the speakers (tap a speaker label or a timestamp in the transcript to fix a wrong one) → generate what you need → export

Audio is sent to the Google Gemini API only when you transcribe and is deleted from Google's servers as soon as transcription finishes. Transcripts and analyses are stored only on this phone.
